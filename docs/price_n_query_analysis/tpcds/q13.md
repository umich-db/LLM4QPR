# TPC-DS Query 13 — PRICE_N Analysis

## Raw SQL

```sql
select avg(ss_quantity) ,avg(ss_ext_sales_price) ,avg(ss_ext_wholesale_cost) ,sum(ss_ext_wholesale_cost) from store_sales ,store ,customer_demographics ,household_demographics ,customer_address ,date_dim where s_store_sk = ss_store_sk and  ss_sold_date_sk = d_date_sk and d_year = 2001 and((ss_hdemo_sk=hd_demo_sk and cd_demo_sk = ss_cdemo_sk and cd_marital_status = 'D' and cd_education_status = '2 yr Degree' and ss_sales_price between 100.00 and 150.00 and hd_dep_count = 3 )or (ss_hdemo_sk=hd_demo_sk and cd_demo_sk = ss_cdemo_sk and cd_marital_status = 'S' and cd_education_status = 'Secondary' and ss_sales_price between 50.00 and 100.00 and hd_dep_count = 1 ) or (ss_hdemo_sk=hd_demo_sk and cd_demo_sk = ss_cdemo_sk and cd_marital_status = 'W' and cd_education_status = 'Advanced Degree' and ss_sales_price between 150.00 and 200.00 and hd_dep_count = 1 )) and((ss_addr_sk = ca_address_sk and ca_country = 'United States' and ca_state in ('CO', 'IL', 'MN') and ss_net_profit between 100 and 200 ) or (ss_addr_sk = ca_address_sk and ca_country = 'United States' and ca_state in ('OH', 'MT', 'NM') and ss_net_profit between 150 and 300 ) or (ss_addr_sk = ca_address_sk and ca_country = 'United States' and ca_state in ('TX', 'MO', 'MI') and ss_net_profit between 50 and 250 ))
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer_address tpcds_ca, customer_demographics tpcds_cd, date_dim tpcds_dd, household_demographics tpcds_hd, store tpcds_s, store_sales tpcds_ss WHERE  tpcds_s.s_store_sk = tpcds_ss.ss_store_sk AND tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk AND tpcds_dd.d_year = 2001
```

## What goes into PRICE

**Tables**: `tpcds_ca` (customer_address), `tpcds_cd` (customer_demographics), `tpcds_dd` (date_dim), `tpcds_hd` (household_demographics), `tpcds_s` (store), `tpcds_ss` (store_sales)

**Joins**:
- `tpcds_s.s_store_sk` = `tpcds_ss.ss_store_sk`
- `tpcds_ss.ss_sold_date_sk` = `tpcds_dd.d_date_sk`

**Filter atoms**:
- `tpcds_dd.d_year`: eq=[2001]

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **Aggregates**: Aggregates in SELECT: AVG(ss_quantity), AVG(ss_ext_sales_price), AVG(ss_ext_wholesale_cost), SUM(ss_ext_wholesale_cost)

## Predicate Reordering

- **BETWEEN → AND-of-comparisons**
  - Before: `col BETWEEN low AND high`
  - After:  `col >= low AND col <= high`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```
tpcds_s.s_store_sk = tpcds_ss.ss_store_sk
tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk
tpcds_dd.d_year = 2001
```
