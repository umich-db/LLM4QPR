# TPC-DS Query 37 — PRICE_N Analysis

## Raw SQL

```sql
select  i_item_id ,i_item_desc ,i_current_price from item, inventory, date_dim, catalog_sales where i_current_price between 22 and 22 + 30 and inv_item_sk = i_item_sk and d_date_sk=inv_date_sk and d_date between cast('2001-06-02' as date) and (cast('2001-06-02' as date) +  60 ) and i_manufact_id in (678,964,918,849) and inv_quantity_on_hand between 100 and 500 and cs_item_sk = i_item_sk group by i_item_id,i_item_desc,i_current_price order by i_item_id limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM catalog_sales tpcds_cs, date_dim tpcds_dd, inventory tpcds_inv, item tpcds_i WHERE  tpcds_inv.inv_item_sk = tpcds_i.i_item_sk AND tpcds_dd.d_date_sk = tpcds_inv.inv_date_sk AND tpcds_cs.cs_item_sk = tpcds_i.i_item_sk AND tpcds_i.i_current_price >= 22 AND tpcds_i.i_current_price <= 22 + 30 AND tpcds_dd.d_date >= 991440000 AND tpcds_dd.d_date <= 996624000) AND tpcds_i.i_manufact_id >= 678.0 AND tpcds_i.i_manufact_id <= 964.0 AND tpcds_inv.inv_quantity_on_hand >= 100 AND tpcds_inv.inv_quantity_on_hand <= 500
```

## What goes into PRICE

**Tables**: `tpcds_cs` (catalog_sales), `tpcds_dd` (date_dim), `tpcds_inv` (inventory), `tpcds_i` (item)

**Joins**:
- `tpcds_cs.cs_item_sk` = `tpcds_i.i_item_sk`
- `tpcds_inv.inv_item_sk` = `tpcds_i.i_item_sk`
- `tpcds_dd.d_date_sk` = `tpcds_inv.inv_date_sk`

**Filter atoms**:
- `tpcds_dd.d_date`: range_low=991440000; range_high=996624000
- `tpcds_i.i_current_price`: range_low=22
- `tpcds_i.i_manufact_id`: range_low=678.0; range_high=964.0
- `tpcds_inv.inv_quantity_on_hand`: range_low=100; range_high=500

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **GroupBy**: GROUP BY: GROUP BY i_item_id, i_item_desc, i_current_price
- **OrderBy**: ORDER BY: ORDER BY i_item_id
- **Limit**: LIMIT: LIMIT 100

## Predicate Reordering

- **BETWEEN → AND-of-comparisons**
  - Before: `col BETWEEN low AND high`
  - After:  `col >= low AND col <= high`
