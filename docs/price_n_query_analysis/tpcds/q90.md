# TPC-DS Query 90 — PRICE_N Analysis

## Raw SQL

```sql
select  cast(amc as decimal(15,4))/cast(pmc as decimal(15,4)) am_pm_ratio from ( select count(*) amc from web_sales, household_demographics , time_dim, web_page where ws_sold_time_sk = time_dim.t_time_sk and ws_ship_hdemo_sk = household_demographics.hd_demo_sk and ws_web_page_sk = web_page.wp_web_page_sk and time_dim.t_hour between 6 and 6+1 and household_demographics.hd_dep_count = 8 and web_page.wp_char_count between 5000 and 5200) at, ( select count(*) pmc from web_sales, household_demographics , time_dim, web_page where ws_sold_time_sk = time_dim.t_time_sk and ws_ship_hdemo_sk = household_demographics.hd_demo_sk and ws_web_page_sk = web_page.wp_web_page_sk and time_dim.t_hour between 14 and 14+1 and household_demographics.hd_dep_count = 8 and web_page.wp_char_count between 5000 and 5200) pt order by am_pm_ratio limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM household_demographics tpcds_hd, time_dim tpcds_td, web_page tpcds_wp, web_sales tpcds_ws WHERE  tpcds_ws.ws_sold_time_sk = tpcds_td.t_time_sk AND tpcds_ws.ws_ship_hdemo_sk = tpcds_hd.hd_demo_sk AND tpcds_ws.ws_web_page_sk = tpcds_wp.wp_web_page_sk AND tpcds_td.t_hour >= 6 AND tpcds_td.t_hour <= 7 AND tpcds_hd.hd_dep_count = 8 AND tpcds_wp.wp_char_count >= 5000 AND tpcds_wp.wp_char_count <= 5200
```

## What goes into PRICE

**Tables**: `tpcds_hd` (household_demographics), `tpcds_td` (time_dim), `tpcds_wp` (web_page), `tpcds_ws` (web_sales)

**Joins**:
- `tpcds_ws.ws_web_page_sk` = `tpcds_wp.wp_web_page_sk`
- `tpcds_ws.ws_sold_time_sk` = `tpcds_td.t_time_sk`
- `tpcds_ws.ws_ship_hdemo_sk` = `tpcds_hd.hd_demo_sk`

**Filter atoms**:
- `tpcds_hd.hd_dep_count`: eq=[8]
- `tpcds_td.t_hour`: range_low=6; range_high=7
- `tpcds_wp.wp_char_count`: range_low=5000; range_high=5200

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)
