# TPC-DS Query 26 — PRICE_N Analysis

## Raw SQL

```sql
select  i_item_id, avg(cs_quantity) agg1, avg(cs_list_price) agg2, avg(cs_coupon_amt) agg3, avg(cs_sales_price) agg4 from catalog_sales, customer_demographics, date_dim, item, promotion where cs_sold_date_sk = d_date_sk and cs_item_sk = i_item_sk and cs_bill_cdemo_sk = cd_demo_sk and cs_promo_sk = p_promo_sk and cd_gender = 'F' and cd_marital_status = 'W' and cd_education_status = 'Primary' and (p_channel_email = 'N' or p_channel_event = 'N') and d_year = 1998 group by i_item_id order by i_item_id limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM catalog_sales tpcds_cs, customer_demographics tpcds_cd, date_dim tpcds_dd, item tpcds_i, promotion tpcds_pr WHERE  tpcds_cs.cs_sold_date_sk = tpcds_dd.d_date_sk AND tpcds_cs.cs_item_sk = tpcds_i.i_item_sk AND tpcds_cs.cs_bill_cdemo_sk = tpcds_cd.cd_demo_sk AND tpcds_cs.cs_promo_sk = tpcds_pr.p_promo_sk AND tpcds_cd.cd_gender = 'F' AND tpcds_cd.cd_marital_status = 'W' AND tpcds_cd.cd_education_status = 'Primary' AND tpcds_dd.d_year = 1998
```
