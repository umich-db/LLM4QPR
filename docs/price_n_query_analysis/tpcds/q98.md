# TPC-DS Query 98 — PRICE_N Analysis

## Raw SQL

```sql
select i_item_id ,i_item_desc ,i_category ,i_class ,i_current_price ,sum(ss_ext_sales_price) as itemrevenue ,sum(ss_ext_sales_price)*100/sum(sum(ss_ext_sales_price)) over (partition by i_class) as revenueratio from store_sales ,item ,date_dim where ss_item_sk = i_item_sk and i_category in ('Jewelry', 'Sports', 'Books') and ss_sold_date_sk = d_date_sk and d_date between cast('2001-01-12' as date) and (cast('2001-01-12' as date) + 30 ) group by i_item_id ,i_item_desc ,i_category ,i_class ,i_current_price order by i_category ,i_class ,i_item_id ,i_item_desc ,revenueratio
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM date_dim tpcds_dd, item tpcds_i, store_sales tpcds_ss WHERE  tpcds_ss.ss_item_sk = tpcds_i.i_item_sk AND tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk AND tpcds_i.i_category = 'Jewelry' AND tpcds_dd.d_date >= 979257600 AND tpcds_dd.d_date <= 981849600)
```

## What goes into PRICE

**Tables**: `tpcds_dd` (date_dim), `tpcds_i` (item), `tpcds_ss` (store_sales)

**Joins**:
- `tpcds_ss.ss_item_sk` = `tpcds_i.i_item_sk`
- `tpcds_ss.ss_sold_date_sk` = `tpcds_dd.d_date_sk`

**Filter atoms**:
- `tpcds_dd.d_date`: range_low=979257600; range_high=981849600
- `tpcds_i.i_category`: eq=['Jewelry']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **WindowFunction**: Window function: SUM(SUM(ss_ext_sales_price)) OVER (PARTITION BY i_class)
- **GroupBy**: GROUP BY: GROUP BY i_item_id, i_item_desc, i_category, i_class, i_current_price
- **Aggregates**: Aggregates in SELECT: SUM(ss_ext_sales_price), SUM(ss_ext_sales_price)
- **OrderBy**: ORDER BY: ORDER BY i_category, i_class, i_item_id, i_item_desc, revenueratio

## Predicate Reordering

- **BETWEEN → AND-of-comparisons**
  - Before: `col BETWEEN low AND high`
  - After:  `col >= low AND col <= high`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```
tpcds_ss.ss_item_sk = tpcds_i.i_item_sk
tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk
tpcds_i.i_category = 'Jewelry'
tpcds_dd.d_date >= 979257600
tpcds_dd.d_date <= 981849600
```
