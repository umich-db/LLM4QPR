# TPC-DS Query 22 — PRICE_N Analysis

## Raw SQL

```sql
select  i_product_name ,i_brand ,i_class ,i_category ,avg(inv_quantity_on_hand) qoh from inventory ,date_dim ,item where inv_date_sk=d_date_sk and inv_item_sk=i_item_sk and d_month_seq between 1212 and 1212 + 11 group by rollup(i_product_name ,i_brand ,i_class ,i_category) order by qoh, i_product_name, i_brand, i_class, i_category limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM date_dim tpcds_dd, inventory tpcds_inv, item tpcds_i WHERE  tpcds_inv.inv_date_sk = tpcds_dd.d_date_sk AND tpcds_inv.inv_item_sk = tpcds_i.i_item_sk AND tpcds_dd.d_month_seq >= 1212 AND tpcds_dd.d_month_seq <= 1223
```

## What goes into PRICE

**Tables**: `tpcds_dd` (date_dim), `tpcds_inv` (inventory), `tpcds_i` (item)

**Joins**:
- `tpcds_inv.inv_date_sk` = `tpcds_dd.d_date_sk`
- `tpcds_inv.inv_item_sk` = `tpcds_i.i_item_sk`

**Filter atoms**:
- `tpcds_dd.d_month_seq`: range_low=1212; range_high=1223

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **GroupBy**: GROUP BY: GROUP BY ROLLUP (i_product_name, i_brand, i_class, i_category)
- **Aggregates**: Aggregates in SELECT: AVG(inv_quantity_on_hand)
- **OrderBy**: ORDER BY: ORDER BY qoh, i_product_name, i_brand, i_class, i_category
- **Limit**: LIMIT: LIMIT 100

## Predicate Reordering

- **BETWEEN → native range atom (PRICE_N)**
  - Before: `col BETWEEN low AND high`
  - After:  `range_low=low, range_high=high  (no >= / <= expansion under PRICE_N)`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```
tpcds_inv.inv_date_sk = tpcds_dd.d_date_sk
tpcds_inv.inv_item_sk = tpcds_i.i_item_sk
tpcds_dd.d_month_seq >= 1212
tpcds_dd.d_month_seq <= 1223
```
