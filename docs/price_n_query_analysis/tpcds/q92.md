# TPC-DS Query 92 — PRICE_N Analysis

## Raw SQL

```sql
select sum(ws_ext_discount_amt)  as "Excess Discount Amount" from web_sales ,item ,date_dim where i_manufact_id = 269 and i_item_sk = ws_item_sk and d_date between '1998-03-18' and (cast('1998-03-18' as date) + 90 ) and d_date_sk = ws_sold_date_sk and ws_ext_discount_amt > ( SELECT 1.3 * avg(ws_ext_discount_amt) FROM web_sales ,date_dim WHERE ws_item_sk = i_item_sk and d_date between '1998-03-18' and (cast('1998-03-18' as date) + 90 ) and d_date_sk = ws_sold_date_sk ) order by sum(ws_ext_discount_amt) limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM date_dim tpcds_dd, item tpcds_i, web_sales tpcds_ws WHERE  tpcds_i.i_item_sk = tpcds_ws.ws_item_sk AND tpcds_dd.d_date_sk = tpcds_ws.ws_sold_date_sk AND tpcds_i.i_manufact_id = 269 AND tpcds_dd.d_date >= '1998-03-18' AND tpcds_dd.d_date <= 897955200)
```

## What goes into PRICE

**Tables**: `tpcds_dd` (date_dim), `tpcds_i` (item), `tpcds_ws` (web_sales)

**Joins**:
- `tpcds_i.i_item_sk` = `tpcds_ws.ws_item_sk`
- `tpcds_dd.d_date_sk` = `tpcds_ws.ws_sold_date_sk`

**Filter atoms**:
- `tpcds_dd.d_date`: range_low=1998-03-18; range_high=897955200
- `tpcds_i.i_manufact_id`: eq=[269]

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **ScalarSubquery**: Scalar subquery `ws_ext_discount_amt GT (SELECT AGG ...)` — goes to LLM residual under PRICE_N
  ```sql
  ws_ext_discount_amt ... ((SELECT 1.3 * AVG(ws_ext_discount_amt) FROM web_sales, date_dim WHERE ws_item_sk...)
  ```
- **Aggregates**: Aggregates in SELECT: SUM(ws_ext_discount_amt)
- **OrderBy**: ORDER BY: ORDER BY SUM(ws_ext_discount_amt)
- **Limit**: LIMIT: LIMIT 100

## Predicate Reordering

- **BETWEEN → AND-of-comparisons**
  - Before: `col BETWEEN low AND high`
  - After:  `col >= low AND col <= high`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```

tpcds_i.i_manufact_id = 269
tpcds_dd.d_date >= '1998-03-18'
```
