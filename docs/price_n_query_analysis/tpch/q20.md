# TPC-H Query 20 — PRICE_N Analysis

## Raw SQL

```sql
select s_name, s_address from supplier, nation where s_suppkey in ( select ps_suppkey from partsupp where ps_partkey in ( select p_partkey from part where p_name like 'ivory%' ) and ps_availqty > ( select 0.5 * sum(l_quantity) from lineitem where l_partkey = ps_partkey and l_suppkey = ps_suppkey and l_shipdate >= date '1996-01-01' and l_shipdate < date '1996-01-01' + interval '1 year' ) ) and s_nationkey = n_nationkey and n_name =  'KENYA' order by s_name
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM nation tpch_n, supplier tpch_s WHERE  tpch_s.s_nationkey = tpch_n.n_nationkey AND tpch_n.n_name = 'KENYA'
```

## What goes into PRICE

**Tables**: `tpch_n` (nation), `tpch_s` (supplier)

**Joins**:
- `tpch_s.s_nationkey` = `tpch_n.n_nationkey`

**Filter atoms**:
- `tpch_n.n_name`: eq=['KENYA']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

- **OrderBy**: ORDER BY: ORDER BY s_name
