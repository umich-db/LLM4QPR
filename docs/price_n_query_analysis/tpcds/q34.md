# TPC-DS Query 34 — PRICE_N Analysis

## Raw SQL

```sql
select c_last_name ,c_first_name ,c_salutation ,c_preferred_cust_flag ,ss_ticket_number ,cnt from (select ss_ticket_number ,ss_customer_sk ,count(*) cnt from store_sales,date_dim,store,household_demographics where store_sales.ss_sold_date_sk = date_dim.d_date_sk and store_sales.ss_store_sk = store.s_store_sk and store_sales.ss_hdemo_sk = household_demographics.hd_demo_sk and (date_dim.d_dom between 1 and 3 or date_dim.d_dom between 25 and 28) and (household_demographics.hd_buy_potential = '>10000' or household_demographics.hd_buy_potential = 'Unknown') and household_demographics.hd_vehicle_count > 0 and (case when household_demographics.hd_vehicle_count > 0 then household_demographics.hd_dep_count/ household_demographics.hd_vehicle_count else null end)  > 1.2 and date_dim.d_year in (1998,1998+1,1998+2) and store.s_county in ('Williamson County','Williamson County','Williamson County','Williamson County', 'Williamson County','Williamson County','Williamson County','Williamson County') group by ss_ticket_number,ss_customer_sk) dn,customer where ss_customer_sk = c_customer_sk and cnt between 15 and 20 order by c_last_name,c_first_name,c_salutation,c_preferred_cust_flag desc, ss_ticket_number
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM date_dim tpcds_dd, household_demographics tpcds_hd, store tpcds_s, store_sales tpcds_ss WHERE  tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk AND tpcds_ss.ss_store_sk = tpcds_s.s_store_sk AND tpcds_ss.ss_hdemo_sk = tpcds_hd.hd_demo_sk AND tpcds_hd.hd_vehicle_count > 0 AND tpcds_s.s_county = 'Williamson County'
```

## What goes into PRICE

- `tpcds_ss.ss_sold_date_sk` = `tpcds_dd.d_date_sk`
- `tpcds_ss.ss_store_sk` = `tpcds_s.s_store_sk`

**Filter atoms**:
- `tpcds_hd.hd_vehicle_count`: range_low=0
- `tpcds_s.s_county`: eq=['Williamson County']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)
