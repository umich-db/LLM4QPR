# TPC-DS Query 55 — PRICE_N Analysis

## Raw SQL

```sql
select  i_brand_id brand_id, i_brand brand, sum(ss_ext_sales_price) ext_price from date_dim, store_sales, item where d_date_sk = ss_sold_date_sk and ss_item_sk = i_item_sk and i_manager_id=36 and d_moy=12 and d_year=2001 group by i_brand, i_brand_id order by ext_price desc, i_brand_id limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM date_dim tpcds_dd, item tpcds_i, store_sales tpcds_ss WHERE  tpcds_dd.d_date_sk = tpcds_ss.ss_sold_date_sk AND tpcds_ss.ss_item_sk = tpcds_i.i_item_sk AND tpcds_i.i_manager_id = 36 AND tpcds_dd.d_moy = 12 AND tpcds_dd.d_year = 2001
```
