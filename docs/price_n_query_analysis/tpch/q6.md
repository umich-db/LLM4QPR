# TPC-H Query 6 — PRICE_N Analysis

## Raw SQL

```sql
select sum(l_extendedprice * l_discount) as revenue from lineitem where l_shipdate >= date '1993-01-01' and l_shipdate < date '1993-01-01' + interval '1 year' and l_discount between 0.07 - 0.01 and 0.07 + 0.01 and l_quantity < 25
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM lineitem tpch_l WHERE  tpch_l.l_shipdate >= 725846400 AND tpch_l.l_shipdate < 725846400 + INTERVAL '1' YEAR AND tpch_l.l_discount >= 0.06 AND tpch_l.l_discount <= 0.08 AND tpch_l.l_quantity < 25
```
