# TPC-H Query 16 — PRICE_N Analysis

## Raw SQL

```sql
select p_brand, p_type, p_size, count(distinct ps_suppkey) as supplier_cnt from partsupp, part where p_partkey = ps_partkey and p_brand <> 'Brand#41' and p_type not like 'MEDIUM BURNISHED%' and p_size in (4, 22, 35, 31, 47, 44, 30, 11) and ps_suppkey not in ( select s_suppkey from supplier where s_comment like '%Customer%Complaints%' ) group by p_brand, p_type, p_size order by supplier_cnt desc, p_brand, p_type, p_size
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM part tpch_p, partsupp tpch_ps WHERE  tpch_p.p_partkey = tpch_ps.ps_partkey AND 1 = 1 AND tpch_p.p_size >= 4.0 AND tpch_p.p_size <= 47.0
```

## What goes into PRICE

**Tables**: `tpch_p` (part), `tpch_ps` (partsupp)

**Joins**:
- `tpch_p.p_partkey` = `tpch_ps.ps_partkey`

**Filter atoms**:
- `1`: eq=[1]
- `tpch_p.p_size`: range_low=4.0; range_high=47.0

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **NotInSubquery**: NOT IN (subquery) on `ps_suppkey` — goes to LLM residual under PRICE_N
  ```sql
  ps_suppkey NOT IN ((SELECT s_suppkey FROM supplier WHERE s_comment LIKE '%Customer%Complaints%'))
  ```
- **GroupBy**: GROUP BY: GROUP BY p_brand, p_type, p_size
- **Aggregates**: Aggregates in SELECT: COUNT(DISTINCT ps_suppkey)
- **OrderBy**: ORDER BY: ORDER BY supplier_cnt DESC, p_brand, p_type, p_size

## Predicate Reordering

- **LIKE → dropped (1 = 1)**
  - Before: `col LIKE 'pattern'`
  - After:  `1 = 1 (tautology, filtered out)`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```
tpch_p.p_partkey = tpch_ps.ps_partkey
1 = 1
tpch_p.p_size >= 4.0
tpch_p.p_size <= 47.0
```
