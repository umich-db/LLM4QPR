# TPC-H Query 5 — PRICE_N Analysis

## Raw SQL

```sql
select n_name, sum(l_extendedprice * (1 - l_discount)) as revenue from customer, orders, lineitem, supplier, nation, region where c_custkey = o_custkey and l_orderkey = o_orderkey and l_suppkey = s_suppkey and c_nationkey = s_nationkey and s_nationkey = n_nationkey and n_regionkey = r_regionkey and r_name = 'AMERICA' and o_orderdate >= date '1993-01-01' and o_orderdate < date '1993-01-01' + interval '1 year' group by n_name order by revenue desc
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer tpch_c, lineitem tpch_l, nation tpch_n, orders tpch_o, region tpch_r, supplier tpch_s WHERE  tpch_c.c_custkey = tpch_o.o_custkey AND tpch_l.l_orderkey = tpch_o.o_orderkey AND tpch_l.l_suppkey = tpch_s.s_suppkey AND tpch_c.c_nationkey = tpch_s.s_nationkey AND tpch_s.s_nationkey = tpch_n.n_nationkey AND tpch_n.n_regionkey = tpch_r.r_regionkey AND tpch_r.r_name = 'AMERICA' AND tpch_o.o_orderdate >= 725846400 AND tpch_o.o_orderdate < 725846400 + INTERVAL '1' YEAR
```

## What goes into PRICE

**Tables**: `tpch_c` (customer), `tpch_l` (lineitem), `tpch_n` (nation), `tpch_o` (orders), `tpch_r` (region), `tpch_s` (supplier)

**Joins**:
- `tpch_n.n_regionkey` = `tpch_r.r_regionkey`
- `tpch_s.s_nationkey` = `tpch_n.n_nationkey`
- `tpch_c.c_nationkey` = `tpch_s.s_nationkey`
- `tpch_l.l_suppkey` = `tpch_s.s_suppkey`
- `tpch_c.c_custkey` = `tpch_o.o_custkey`
- `tpch_l.l_orderkey` = `tpch_o.o_orderkey`

**Filter atoms**:
- `tpch_o.o_orderdate`: range_low=725846400
- `tpch_r.r_name`: eq=['AMERICA']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **GroupBy**: GROUP BY: GROUP BY n_name
- **Aggregates**: Aggregates in SELECT: SUM(l_extendedprice * (1 - l_discount))
- **OrderBy**: ORDER BY: ORDER BY revenue DESC
