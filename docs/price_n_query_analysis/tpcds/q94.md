# TPC-DS Query 94 — PRICE_N Analysis

## Raw SQL

```sql
select count(distinct ws_order_number) as "order count" ,sum(ws_ext_ship_cost) as "total shipping cost" ,sum(ws_net_profit) as "total net profit" from web_sales ws1 ,date_dim ,customer_address ,web_site where d_date between '1999-5-01' and (cast('1999-5-01' as date) + 60 ) and ws1.ws_ship_date_sk = d_date_sk and ws1.ws_ship_addr_sk = ca_address_sk and ca_state = 'TX' and ws1.ws_web_site_sk = web_site_sk and web_company_name = 'pri' and exists (select * from web_sales ws2 where ws1.ws_order_number = ws2.ws_order_number and ws1.ws_warehouse_sk <> ws2.ws_warehouse_sk) and not exists(select * from web_returns wr1 where ws1.ws_order_number = wr1.wr_order_number) order by count(distinct ws_order_number) limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer_address tpcds_ca, date_dim tpcds_dd, web_sales tpcds_ws, web_site tpcds_wsi WHERE  tpcds_ws.ws_ship_date_sk = tpcds_dd.d_date_sk AND tpcds_ws.ws_ship_addr_sk = tpcds_ca.ca_address_sk AND tpcds_ws.ws_web_site_sk = tpcds_wsi.web_site_sk AND tpcds_dd.d_date >= '1999-5-01' AND tpcds_dd.d_date <= 930700800) AND tpcds_ca.ca_state = 'TX' AND tpcds_wsi.web_company_name = 'pri'
```

## What goes into PRICE

**Tables**: `tpcds_ca` (customer_address), `tpcds_dd` (date_dim), `tpcds_ws` (web_sales), `tpcds_wsi` (web_site)

**Joins**:
- `tpcds_ws.ws_web_site_sk` = `tpcds_wsi.web_site_sk`
- `tpcds_ws.ws_ship_date_sk` = `tpcds_dd.d_date_sk`
- `tpcds_ws.ws_ship_addr_sk` = `tpcds_ca.ca_address_sk`

**Filter atoms**:
- `tpcds_ca.ca_state`: eq=['TX']
- `tpcds_dd.d_date`: range_low=1999-5-01; range_high=930700800
- `tpcds_wsi.web_company_name`: eq=['pri']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **NotExists**: NOT EXISTS subquery — goes to LLM residual under PRICE_N
  ```sql
  NOT EXISTS (SELECT * FROM web_returns AS wr1 WHERE ws1.ws_order_number = wr1.wr_order_number)
  ```
- **Exists**: EXISTS subquery — goes to LLM residual under PRICE_N
  ```sql
  EXISTS (SELECT * FROM web_sales AS ws2 WHERE ws1.ws_order_number = ws2.ws_order_number AND ws1.ws_warehouse_...)
  ```
- **Aggregates**: Aggregates in SELECT: COUNT(DISTINCT ws_order_number), SUM(ws_ext_ship_cost), SUM(ws_net_profit)
- **OrderBy**: ORDER BY: ORDER BY COUNT(DISTINCT ws_order_number)
- **Limit**: LIMIT: LIMIT 100

## Predicate Reordering

- **BETWEEN → AND-of-comparisons**
  - Before: `col BETWEEN low AND high`
  - After:  `col >= low AND col <= high`
