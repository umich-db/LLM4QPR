# TPC-H Query 2 — PRICE_N Analysis

## Raw SQL

```sql
select s_acctbal, s_name, n_name, p_partkey, p_mfgr, s_address, s_phone, s_comment from part, supplier, partsupp, nation, region where p_partkey = ps_partkey and s_suppkey = ps_suppkey and p_size = 38 and p_type like '%STEEL' and s_nationkey = n_nationkey and n_regionkey = r_regionkey and r_name = 'ASIA' and ps_supplycost = (select min(ps_supplycost) from partsupp, supplier, nation, region where p_partkey = ps_partkey and s_suppkey = ps_suppkey and s_nationkey = n_nationkey and n_regionkey = r_regionkey and r_name = 'ASIA') order by s_acctbal desc, n_name, s_name, p_partkey
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM nation tpch_n, part tpch_p, partsupp tpch_ps, region tpch_r, supplier tpch_s WHERE  tpch_p.p_partkey = tpch_ps.ps_partkey AND tpch_s.s_suppkey = tpch_ps.ps_suppkey AND tpch_s.s_nationkey = tpch_n.n_nationkey AND tpch_n.n_regionkey = tpch_r.r_regionkey AND tpch_p.p_size = 38 AND tpch_r.r_name = 'ASIA'
```

## What goes into PRICE

**Tables**: `tpch_n` (nation), `tpch_p` (part), `tpch_ps` (partsupp), `tpch_r` (region), `tpch_s` (supplier)

**Joins**:
- `tpch_n.n_regionkey` = `tpch_r.r_regionkey`
- `tpch_s.s_nationkey` = `tpch_n.n_nationkey`
- `tpch_p.p_partkey` = `tpch_ps.ps_partkey`
- `tpch_s.s_suppkey` = `tpch_ps.ps_suppkey`

**Filter atoms**:
- `tpch_p.p_size`: eq=[38]
- `tpch_r.r_name`: eq=['ASIA']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **ScalarSubquery**: Scalar subquery `ps_supplycost EQ (SELECT AGG ...)` — goes to LLM residual under PRICE_N

  ```sql
  ps_supplycost ... ((SELECT MIN(ps_supplycost) FROM partsupp, supplier, nation, region WHERE p_partk...)
  ```
- **OrderBy**: ORDER BY: ORDER BY s_acctbal DESC, n_name, s_name, p_partkey

## Predicate Reordering

- **LIKE → dropped (1 = 1)**
  - Before: `col LIKE 'pattern'`
  - After:  `1 = 1 (tautology, filtered out)`
