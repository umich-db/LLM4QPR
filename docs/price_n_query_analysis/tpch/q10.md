# TPC-H Query 10 — PRICE_N Analysis

## Raw SQL

```sql
select c_custkey, c_name, sum(l_extendedprice * (1 - l_discount)) as revenue, c_acctbal, n_name, c_address, c_phone, c_comment from customer, orders, lineitem, nation where c_custkey = o_custkey and l_orderkey = o_orderkey and o_orderdate >= date '1993-11-01' and o_orderdate < date '1993-11-01' + interval '3 months' and l_returnflag = 'R' and c_nationkey = n_nationkey group by c_custkey, c_name, c_acctbal, c_phone, n_name, c_address, c_comment order by revenue desc
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer tpch_c, lineitem tpch_l, nation tpch_n, orders tpch_o WHERE  tpch_c.c_custkey = tpch_o.o_custkey AND tpch_l.l_orderkey = tpch_o.o_orderkey AND tpch_c.c_nationkey = tpch_n.n_nationkey AND tpch_o.o_orderdate >= 752112000 AND tpch_o.o_orderdate < 752112000 + INTERVAL '3' MONTHS AND tpch_l.l_returnflag = 'R'
```

## What goes into PRICE

**Tables**: `tpch_c` (customer), `tpch_l` (lineitem), `tpch_n` (nation), `tpch_o` (orders)

**Joins**:
- `tpch_c.c_nationkey` = `tpch_n.n_nationkey`
- `tpch_c.c_custkey` = `tpch_o.o_custkey`
- `tpch_l.l_orderkey` = `tpch_o.o_orderkey`

**Filter atoms**:
- `tpch_l.l_returnflag`: eq=['R']
- `tpch_o.o_orderdate`: range_low=752112000

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **GroupBy**: GROUP BY: GROUP BY c_custkey, c_name, c_acctbal, c_phone, n_name, c_address, c_comment
- **Aggregates**: Aggregates in SELECT: SUM(l_extendedprice * (1 - l_discount))
- **OrderBy**: ORDER BY: ORDER BY revenue DESC

## Predicate Reordering

- **Date literals → epoch days**
  - Before: `...erkey = o_orderkey AND o_orderdate >= CAST('1993-11-01' AS DATE) AND o_orderdate < CAST('1993-11-01' AS DATE)...`
  - After:  `SELECT c_custkey, c_name, SUM(l_extendedprice * (1 - l_discount)) AS revenue, c_acctbal, n_name, c_address, c_phone, c_c`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```
tpch_c.c_custkey = tpch_o.o_custkey
tpch_l.l_orderkey = tpch_o.o_orderkey
tpch_c.c_nationkey = tpch_n.n_nationkey
tpch_o.o_orderdate >= 752112000

tpch_l.l_returnflag = 'R'
```
