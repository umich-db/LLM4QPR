# TPC-DS Query 71 — PRICE_N Analysis

## Raw SQL

```sql
select i_brand_id brand_id, i_brand brand,t_hour,t_minute, sum(ext_price) ext_price from item, (select ws_ext_sales_price as ext_price, ws_sold_date_sk as sold_date_sk, ws_item_sk as sold_item_sk, ws_sold_time_sk as time_sk from web_sales,date_dim where d_date_sk = ws_sold_date_sk and d_moy=12 and d_year=2000 union all select cs_ext_sales_price as ext_price, cs_sold_date_sk as sold_date_sk, cs_item_sk as sold_item_sk, cs_sold_time_sk as time_sk from catalog_sales,date_dim where d_date_sk = cs_sold_date_sk and d_moy=12 and d_year=2000 union all select ss_ext_sales_price as ext_price, ss_sold_date_sk as sold_date_sk, ss_item_sk as sold_item_sk, ss_sold_time_sk as time_sk from store_sales,date_dim where d_date_sk = ss_sold_date_sk and d_moy=12 and d_year=2000 ) tmp,time_dim where sold_item_sk = i_item_sk and i_manager_id=1 and time_sk = t_time_sk and (t_meal_time = 'breakfast' or t_meal_time = 'dinner') group by i_brand, i_brand_id,t_hour,t_minute order by ext_price desc, i_brand_id
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM item tpcds_i, time_dim tpcds_td WHERE  sold_item_sk = tpcds_i.i_item_sk AND time_sk = tpcds_td.t_time_sk AND tpcds_i.i_manager_id = 1
```

## What goes into PRICE

**Tables**: `tpcds_i` (item), `tpcds_td` (time_dim)

**Joins**:
- `sold_item_sk` = `tpcds_i.i_item_sk`
- `time_sk` = `tpcds_td.t_time_sk`

**Filter atoms**:
- `tpcds_i.i_manager_id`: eq=[1]

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **DerivedTable**: Derived table alias `tmp`
  ```sql
  FROM ((SELECT ws_ext_sales_price AS ext_price, ws_sold_date_sk AS sold_date_sk, ws_item_sk AS sold_item_sk, ws_sold_time_sk AS...) AS tmp
  ```
- **Union**: Union operator — only first SELECT branch flows to PRICE
  ```sql
  SELECT ws_ext_sales_price AS ext_price, ws_sold_date_sk AS sold_date_sk, ws_item_sk AS sold_item_sk, ws_sold_time_sk AS ...
  ```
- **GroupBy**: GROUP BY: GROUP BY i_brand, i_brand_id, t_hour, t_minute
- **Aggregates**: Aggregates in SELECT: SUM(ext_price)
- **OrderBy**: ORDER BY: ORDER BY ext_price DESC, i_brand_id

## Predicate Reordering

- **OR → IN rewrite**
  - Before: `...AND (t_meal_time = 'breakfast' OR t_meal_time = 'dinner') GROUP BY i_brand, i_brand_id, t_hour, t_minute ORDER...`
  - After:  `...= t_time_sk AND ((t_meal_time IN ('breakfast', 'dinner'))) GROUP BY i_brand, i_brand_id, t_hour, t_minute ORD...`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```
sold_item_sk = tpcds_i.i_item_sk
time_sk = tpcds_td.t_time_sk
tpcds_i.i_manager_id = 1
```
