# TPC-DS Query 69 — PRICE_N Analysis

## Raw SQL

```sql
select cd_gender, cd_marital_status, cd_education_status, count(*) cnt1, cd_purchase_estimate, count(*) cnt2, cd_credit_rating, count(*) cnt3 from customer c,customer_address ca,customer_demographics where c.c_current_addr_sk = ca.ca_address_sk and ca_state in ('CO','IL','MN') and cd_demo_sk = c.c_current_cdemo_sk and exists (select * from store_sales,date_dim where c.c_customer_sk = ss_customer_sk and ss_sold_date_sk = d_date_sk and d_year = 1999 and d_moy between 1 and 1+2) and (not exists (select * from web_sales,date_dim where c.c_customer_sk = ws_bill_customer_sk and ws_sold_date_sk = d_date_sk and d_year = 1999 and d_moy between 1 and 1+2) and not exists (select * from catalog_sales,date_dim where c.c_customer_sk = cs_ship_customer_sk and cs_sold_date_sk = d_date_sk and d_year = 1999 and d_moy between 1 and 1+2)) group by cd_gender, cd_marital_status, cd_education_status, cd_purchase_estimate, cd_credit_rating order by cd_gender, cd_marital_status, cd_education_status, cd_purchase_estimate, cd_credit_rating limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer tpcds_cu, customer_address tpcds_ca, customer_demographics tpcds_cd WHERE  tpcds_cu.c_current_addr_sk = tpcds_ca.ca_address_sk AND tpcds_cd.cd_demo_sk = tpcds_cu.c_current_cdemo_sk AND tpcds_ca.ca_state = 'CO'
```

## What goes into PRICE

**Tables**: `tpcds_cu` (customer), `tpcds_ca` (customer_address), `tpcds_cd` (customer_demographics)

**Joins**:
- `tpcds_cu.c_current_addr_sk` = `tpcds_ca.ca_address_sk`
- `tpcds_cd.cd_demo_sk` = `tpcds_cu.c_current_cdemo_sk`

**Filter atoms**:
- `tpcds_ca.ca_state`: eq=['CO']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)
