# TPC-H Query 17 — PRICE_N Analysis

## Raw SQL

```sql
select sum(l_extendedprice) / 7.0 as avg_yearly from lineitem, part where p_partkey = l_partkey and p_brand = 'Brand#12' and p_container = 'SM BAG' and l_quantity < ( select 0.2 * avg(l_quantity) from lineitem where l_partkey = p_partkey )
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM lineitem tpch_l, part tpch_p WHERE  tpch_p.p_partkey = tpch_l.l_partkey AND tpch_p.p_brand = 'Brand#12' AND tpch_p.p_container = 'SM BAG'
```

## What goes into PRICE

**Tables**: `tpch_l` (lineitem), `tpch_p` (part)

**Joins**:
- `tpch_p.p_partkey` = `tpch_l.l_partkey`

**Filter atoms**:
- `tpch_p.p_brand`: eq=['Brand#12']
- `tpch_p.p_container`: eq=['SM BAG']

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **ScalarSubquery**: Scalar subquery `l_quantity LT (SELECT AGG ...)` — goes to LLM residual under PRICE_N
  ```sql
  l_quantity ... ((SELECT 0.2 * AVG(l_quantity) FROM lineitem WHERE l_partkey = p_partkey))
  ```
- **Aggregates**: Aggregates in SELECT: SUM(l_extendedprice)
