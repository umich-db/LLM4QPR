# TPC-DS Query 3 — PRICE_N Analysis

## Raw SQL

```sql
select  dt.d_year ,item.i_brand_id brand_id ,item.i_brand brand ,sum(ss_ext_sales_price) sum_agg from  date_dim dt ,store_sales ,item where dt.d_date_sk = store_sales.ss_sold_date_sk and store_sales.ss_item_sk = item.i_item_sk and item.i_manufact_id = 436 and dt.d_moy=12 group by dt.d_year ,item.i_brand ,item.i_brand_id order by dt.d_year ,sum_agg desc ,brand_id limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM date_dim tpcds_dd, item tpcds_i, store_sales tpcds_ss WHERE  tpcds_dd.d_date_sk = tpcds_ss.ss_sold_date_sk AND tpcds_ss.ss_item_sk = tpcds_i.i_item_sk AND tpcds_i.i_manufact_id = 436 AND tpcds_dd.d_moy = 12
```

## What goes into PRICE

**Tables**: `tpcds_dd` (date_dim), `tpcds_i` (item), `tpcds_ss` (store_sales)

**Joins**:
- `tpcds_dd.d_date_sk` = `tpcds_ss.ss_sold_date_sk`
- `tpcds_ss.ss_item_sk` = `tpcds_i.i_item_sk`

**Filter atoms**:
- `tpcds_dd.d_moy`: eq=[12]
- `tpcds_i.i_manufact_id`: eq=[436]

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **GroupBy**: GROUP BY: GROUP BY dt.d_year, item.i_brand, item.i_brand_id
- **Aggregates**: Aggregates in SELECT: SUM(ss_ext_sales_price)
- **OrderBy**: ORDER BY: ORDER BY dt.d_year, sum_agg DESC, brand_id
- **Limit**: LIMIT: LIMIT 100
