# TPC-DS Query 48 — PRICE_N Analysis

## Raw SQL

```sql
select sum (ss_quantity) from store_sales, store, customer_demographics, customer_address, date_dim where s_store_sk = ss_store_sk and  ss_sold_date_sk = d_date_sk and d_year = 1998 and ( ( cd_demo_sk = ss_cdemo_sk and cd_marital_status = 'M' and cd_education_status = '4 yr Degree' and ss_sales_price between 100.00 and 150.00 ) or ( cd_demo_sk = ss_cdemo_sk and cd_marital_status = 'D' and cd_education_status = 'Primary' and ss_sales_price between 50.00 and 100.00 ) or ( cd_demo_sk = ss_cdemo_sk and cd_marital_status = 'U' and cd_education_status = 'Advanced Degree' and ss_sales_price between 150.00 and 200.00 ) ) and ( ( ss_addr_sk = ca_address_sk and ca_country = 'United States' and ca_state in ('KY', 'GA', 'NM') and ss_net_profit between 0 and 2000 ) or (ss_addr_sk = ca_address_sk and ca_country = 'United States' and ca_state in ('MT', 'OR', 'IN') and ss_net_profit between 150 and 3000 ) or (ss_addr_sk = ca_address_sk and ca_country = 'United States' and ca_state in ('WI', 'MO', 'WV') and ss_net_profit between 50 and 25000 ) )
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer_address tpcds_ca, customer_demographics tpcds_cd, date_dim tpcds_dd, store tpcds_s, store_sales tpcds_ss WHERE  tpcds_s.s_store_sk = tpcds_ss.ss_store_sk AND tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk AND tpcds_dd.d_year = 1998
```

## What goes into PRICE

**Tables**: `tpcds_ca` (customer_address), `tpcds_cd` (customer_demographics), `tpcds_dd` (date_dim), `tpcds_s` (store), `tpcds_ss` (store_sales)

**Joins**:
- `tpcds_s.s_store_sk` = `tpcds_ss.ss_store_sk`
- `tpcds_ss.ss_sold_date_sk` = `tpcds_dd.d_date_sk`

**Filter atoms**:
- `tpcds_dd.d_year`: eq=[1998]

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **Aggregates**: Aggregates in SELECT: SUM(ss_quantity)

## Predicate Reordering

- **BETWEEN → native range atom (PRICE_N)**
  - Before: `col BETWEEN low AND high`
  - After:  `range_low=low, range_high=high  (no >= / <= expansion under PRICE_N)`

## DNF (WHERE clause, post-NNF)

Single conjunctive clause:
```
tpcds_s.s_store_sk = tpcds_ss.ss_store_sk
tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk
tpcds_dd.d_year = 1998
```
