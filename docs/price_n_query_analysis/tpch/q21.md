# TPC-H Query 21 — PRICE_N Analysis

## Raw SQL

```sql
select s_name, count(*) as numwait from supplier, lineitem l1, orders, nation where s_suppkey = l1.l_suppkey and o_orderkey = l1.l_orderkey and o_orderstatus = 'F' and l1.l_receiptdate > l1.l_commitdate and exists ( select * from lineitem l2 where l2.l_orderkey = l1.l_orderkey and l2.l_suppkey <> l1.l_suppkey ) and not exists ( select * from lineitem l3 where l3.l_orderkey = l1.l_orderkey and l3.l_suppkey <> l1.l_suppkey and l3.l_receiptdate > l3.l_commitdate ) and s_nationkey = n_nationkey and n_name = 'PERU' group by s_name order by numwait desc, s_name
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM lineitem tpch_l, nation tpch_n, orders tpch_o, supplier tpch_s WHERE  tpch_s.s_suppkey = tpch_l.l_suppkey AND tpch_o.o_orderkey = tpch_l.l_orderkey AND tpch_s.s_nationkey = tpch_n.n_nationkey AND tpch_o.o_orderstatus = 'F' AND tpch_n.n_name = 'PERU'
```

## What goes into PRICE

**Tables**: `tpch_l` (lineitem), `tpch_n` (nation), `tpch_o` (orders), `tpch_s` (supplier)

**Joins**:
- `tpch_s.s_nationkey` = `tpch_n.n_nationkey`
- `tpch_s.s_suppkey` = `tpch_l.l_suppkey`
- `tpch_o.o_orderkey` = `tpch_l.l_orderkey`

**Filter atoms**:
- `tpch_n.n_name`: eq=['PERU']
- `tpch_o.o_orderstatus`: eq=['F']

**Pairwise atoms (same-table col-op-col)**:
- `l1.l_receiptdate` > `l1.l_commitdate`
- `l3.l_receiptdate` > `l3.l_commitdate`

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **GroupBy**: GROUP BY: GROUP BY s_name
- **Aggregates**: Aggregates in SELECT: COUNT(*)
- **OrderBy**: ORDER BY: ORDER BY numwait DESC, s_name

## Predicate Reordering

*(no transformations fired — no NOT push-down, no OR→IN, no date literals)*

tpch_o.o_orderstatus = 'F'
