# TPC-DS Query 7 — PRICE_N Analysis

## Raw SQL

```sql
select  i_item_id, avg(ss_quantity) agg1, avg(ss_list_price) agg2, avg(ss_coupon_amt) agg3, avg(ss_sales_price) agg4 from store_sales, customer_demographics, date_dim, item, promotion where ss_sold_date_sk = d_date_sk and ss_item_sk = i_item_sk and ss_cdemo_sk = cd_demo_sk and ss_promo_sk = p_promo_sk and cd_gender = 'F' and cd_marital_status = 'W' and cd_education_status = 'Primary' and (p_channel_email = 'N' or p_channel_event = 'N') and d_year = 1998 group by i_item_id order by i_item_id limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer_demographics tpcds_cd, date_dim tpcds_dd, item tpcds_i, promotion tpcds_pr, store_sales tpcds_ss WHERE  tpcds_ss.ss_sold_date_sk = tpcds_dd.d_date_sk AND tpcds_ss.ss_item_sk = tpcds_i.i_item_sk AND tpcds_ss.ss_cdemo_sk = tpcds_cd.cd_demo_sk AND tpcds_ss.ss_promo_sk = tpcds_pr.p_promo_sk AND tpcds_cd.cd_gender = 'F' AND tpcds_cd.cd_marital_status = 'W' AND tpcds_cd.cd_education_status = 'Primary' AND tpcds_dd.d_year = 1998
```
