# TPC-H Query 18 — PRICE_N Analysis

## Raw SQL

```sql
select c_name, c_custkey, o_orderkey, o_orderdate, o_totalprice, sum(l_quantity) from customer, orders, lineitem where o_orderkey in ( select l_orderkey from lineitem group by l_orderkey having sum(l_quantity) > 313 ) and c_custkey = o_custkey and o_orderkey = l_orderkey group by c_name, c_custkey, o_orderkey, o_orderdate, o_totalprice order by o_totalprice desc, o_orderdate
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer tpch_c, lineitem tpch_l, orders tpch_o WHERE  tpch_c.c_custkey = tpch_o.o_custkey AND tpch_o.o_orderkey = tpch_l.l_orderkey
```

## What goes into PRICE

**Tables**: `tpch_c` (customer), `tpch_l` (lineitem), `tpch_o` (orders)

**Joins**:
- `tpch_c.c_custkey` = `tpch_o.o_custkey`
- `tpch_o.o_orderkey` = `tpch_l.l_orderkey`

**Filter atoms**: (none)

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **InSubquery**: IN (subquery) on `o_orderkey` — goes to LLM residual under PRICE_N

- **GroupBy**: GROUP BY: GROUP BY c_name, c_custkey, o_orderkey, o_orderdate, o_totalprice
- **Aggregates**: Aggregates in SELECT: SUM(l_quantity)
- **OrderBy**: ORDER BY: ORDER BY o_totalprice DESC, o_orderdate
- **Having**: HAVING: HAVING SUM(l_quantity) > 313
