# TPC-H Query 7 — PRICE_N Analysis

## Raw SQL

```sql
select supp_nation, cust_nation, l_year, sum(volume) as revenue from ( select n1.n_name as supp_nation, n2.n_name as cust_nation, extract(year from l_shipdate) as l_year, l_extendedprice * (1 - l_discount) as volume from supplier, lineitem, orders, customer, nation n1, nation n2 where s_suppkey = l_suppkey and o_orderkey = l_orderkey and c_custkey = o_custkey and s_nationkey = n1.n_nationkey and c_nationkey = n2.n_nationkey and ( (n1.n_name = 'MOZAMBIQUE' and n2.n_name = 'UNITED KINGDOM') or (n1.n_name = 'UNITED KINGDOM' and n2.n_name = 'MOZAMBIQUE') ) and l_shipdate between date '1995-01-01' and date '1996-12-31' ) as shipping group by supp_nation, cust_nation, l_year order by supp_nation, cust_nation, l_year
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM customer tpch_c, lineitem tpch_l, nation tpch_n, orders tpch_o, supplier tpch_s WHERE  tpch_s.s_suppkey = tpch_l.l_suppkey AND tpch_o.o_orderkey = tpch_l.l_orderkey AND tpch_c.c_custkey = tpch_o.o_custkey AND tpch_s.s_nationkey = tpch_n.n_nationkey AND tpch_c.c_nationkey = tpch_n.n_nationkey AND tpch_l.l_shipdate >= 788918400 AND tpch_l.l_shipdate <= 851990400
```

## What goes into PRICE

**Tables**: `tpch_c` (customer), `tpch_l` (lineitem), `tpch_n` (nation), `tpch_o` (orders), `tpch_s` (supplier)

**Joins**:
- `tpch_c.c_nationkey` = `tpch_n.n_nationkey`
- `tpch_s.s_nationkey` = `tpch_n.n_nationkey`
- `tpch_c.c_custkey` = `tpch_o.o_custkey`
- `tpch_s.s_suppkey` = `tpch_l.l_suppkey`
- `tpch_o.o_orderkey` = `tpch_l.l_orderkey`

**Filter atoms**:
- `tpch_l.l_shipdate`: range_low=788918400; range_high=851990400

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **DerivedTable**: Derived table alias `shipping`
  ```sql
  FROM ((SELECT n1.n_name AS supp_nation, n2.n_name AS cust_nation, EXTRACT(YEAR FROM l_shipdate) AS l_year, l_extendedprice * (...) AS shipping
  ```
- **GroupBy**: GROUP BY: GROUP BY supp_nation, cust_nation, l_year
- **Aggregates**: Aggregates in SELECT: SUM(volume)
- **OrderBy**: ORDER BY: ORDER BY supp_nation, cust_nation, l_year

## Predicate Reordering

- **BETWEEN → native range atom (PRICE_N)**
  - Before: `col BETWEEN low AND high`
  - After:  `range_low=low, range_high=high  (no >= / <= expansion under PRICE_N)`
