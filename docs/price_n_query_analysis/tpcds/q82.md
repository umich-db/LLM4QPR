# TPC-DS Query 82 — PRICE_N Analysis

## Raw SQL

```sql
select  i_item_id ,i_item_desc ,i_current_price from item, inventory, date_dim, store_sales where i_current_price between 30 and 30+30 and inv_item_sk = i_item_sk and d_date_sk=inv_date_sk and d_date between cast('2002-05-30' as date) and (cast('2002-05-30' as date) +  60 ) and i_manufact_id in (437,129,727,663) and inv_quantity_on_hand between 100 and 500 and ss_item_sk = i_item_sk group by i_item_id,i_item_desc,i_current_price order by i_item_id limit 100
```

## Transformed SQL (input to PRICE)

```sql
SELECT COUNT(*) FROM date_dim tpcds_dd, inventory tpcds_inv, item tpcds_i, store_sales tpcds_ss WHERE  tpcds_inv.inv_item_sk = tpcds_i.i_item_sk AND tpcds_dd.d_date_sk = tpcds_inv.inv_date_sk AND tpcds_ss.ss_item_sk = tpcds_i.i_item_sk AND tpcds_i.i_current_price >= 30 AND tpcds_i.i_current_price <= 30 + 30 AND tpcds_dd.d_date >= 1022716800 AND tpcds_dd.d_date <= 1027900800) AND tpcds_i.i_manufact_id >= 129.0 AND tpcds_i.i_manufact_id <= 727.0 AND tpcds_inv.inv_quantity_on_hand >= 100 AND tpcds_inv.inv_quantity_on_hand <= 500
```

## What goes into PRICE

**Tables**: `tpcds_dd` (date_dim), `tpcds_inv` (inventory), `tpcds_i` (item), `tpcds_ss` (store_sales)

**Joins**:
- `tpcds_ss.ss_item_sk` = `tpcds_i.i_item_sk`
- `tpcds_inv.inv_item_sk` = `tpcds_i.i_item_sk`
- `tpcds_dd.d_date_sk` = `tpcds_inv.inv_date_sk`

**Filter atoms**:
- `tpcds_dd.d_date`: range_low=1022716800; range_high=1027900800
- `tpcds_i.i_current_price`: range_low=30
- `tpcds_i.i_manufact_id`: range_low=129.0; range_high=727.0
- `tpcds_inv.inv_quantity_on_hand`: range_low=100; range_high=500

**Pairwise atoms (col-op-col)**: (none)

**Cross-table non-equi atoms**: (none)

## LLM Residual Constructs

- **GroupBy**: GROUP BY: GROUP BY i_item_id, i_item_desc, i_current_price
- **OrderBy**: ORDER BY: ORDER BY i_item_id
- **Limit**: LIMIT: LIMIT 100

## Predicate Reordering

- **BETWEEN → native range atom (PRICE_N)**
  - Before: `col BETWEEN low AND high`
  - After:  `range_low=low, range_high=high  (no >= / <= expansion under PRICE_N)`
